# 測定原理・精度の注意

1. 80Hz〜16kHzの指数スイープを作り、選択した出力機器で再生。
2. 同じ時間枠で選択した入力機器から48kHzモノラル録音。
3. FFTで録音/出力の周波数比を、微小な正則化を含む最小二乗型の伝達関数として推定。
4. 対数周波数グリッドへ補間し、軽く平滑化。1kHzを0dBとして形状を表示。
5. 2回目の測定から基準測定との差を表示可能。

**現在の結果は「スピーカー × 部屋 × マイク × OS処理」の伝達特性です。** マイクがフラットとは限らず、MacBook内蔵機器も校正済み基準ではありません。またビームフォーミング、マイクモード、DSP、音量連動EQ、保護リミッターが影響する可能性があります。

再現性を確保するため、設置距離・方向・部屋・サンプルレート・Macのスピーカー/入力音量を一定にし、マイクモードは加工の少ない設定を使います。周囲の雑音や内蔵マイクを手で塞ぐことに注意。クリップは録音ピークで検出しますが、マイクやスピーカーでの非線形歪みを検出できるわけではありません。

現方式の簡易FFT比には、反射音、時間窓、ノイズ、スイープの端域などの影響が残ります。本格的精度が必要になった段階で同期・時間窓処理・繰り返し平均・高調波分離を追加し、校正済み測定用マイクで検証してください。USB/HDMI機器の出力レベルと内部DSPは別途注意が必要です。

## 今回の実機確認

2026-10-18のMacBook Pro（M1 Pro）確認ではGUI起動とデバイス一覧表示までを確認しましたが、実際の再生・録音は完了していません。したがって、この作業で得た実機の周波数特性データはありません。自動テストのループバック波形は合成信号であり、内蔵スピーカーやマイクの測定結果ではありません。PortAudioの48kHz入力形式確認がタイムアウトしたため、実音響測定を再開する際は先に入力ストリームとマイク権限を確認してください。詳細は `DEVICE_TEST.md` を参照してください。
